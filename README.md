# Calculate-app

時間制限つきの暗算トレーニングWebアプリです。問題の数値・種類は毎問ランダムに生成されます。

## コース

### 小学生コース

- 正の整数だけを使用
- たし算 / ひき算 / かけ算 / わり算をランダム出題
- ひき算は答えが正の数になるように生成
- わり算は割り切れる問題を生成

### 中学生コース

以下を毎問ランダムに出題します。

- 正負の数
- 分数
- 指数
- 文字式への代入
- 一次方程式

分数は `3/4` のように入力できます。

## 共通機能

- 難易度：やさしい / ふつう / むずかしい
- ゲーム全体の制限時間：30 / 60 / 90秒
- 1問ごとの制限時間：3 / 5 / 10秒
- キーボード入力・画面テンキー入力
- スコア、連続正解、正答率、平均回答時間
- 間違えた問題の復習
- 小学生・中学生コース別の自己ベスト保存
- スマホ対応

## 使い方

`index.html` をブラウザで開くだけで遊べます。

GitHub Pagesを有効にすると、Web上でも公開できます。
