# Calculate-app

時間制限つきの暗算トレーニングWebアプリです。

## 主な機能

- 難易度：やさしい / ふつう / むずかしい
- 計算：たし算 / ひき算 / かけ算 / わり算
- ゲーム全体の制限時間：30 / 60 / 90秒
- 1問ごとの制限時間：3 / 5 / 10秒
- キーボード入力・画面テンキー入力
- スコア、連続正解、正答率、平均回答時間
- 間違えた問題の復習
- 自己ベストをブラウザに保存
- スマホ対応

## 使い方

`index.html` をブラウザで開くだけで遊べます。

GitHub Pagesを有効にすると、Web上でも公開できます。
